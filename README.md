# GitHub Tweaks

A small Chrome extension (works in any Chromium browser, such as Helium, Arc, Brave or Edge) that makes a few things on github.com nicer:

- **Image gallery.** Clicking an image in a README, issue, PR description or comment opens it in a Medium-style lightbox instead of a new tab. Every image on the page is in the gallery, with previous/next buttons, a thumbnail strip, and keyboard navigation (← → to move, Home/End to jump, Esc to close). ⌘-click still opens the image in a new tab.
- **Full-height Actions graph.** Removes the 600px height cap on the workflow run graph in GitHub Actions, so large workflows show without scrolling inside the canvas.

## Install

1. Clone or download this repo.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and pick the repo folder.

After pulling updates, click the reload icon on the extension's card and refresh any open GitHub tabs.
